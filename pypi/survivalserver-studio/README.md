# survivalserver-studio

This name is a misspelling. The Python client for the Survival Servers Studio API is
[survivalservers-studio](https://pypi.org/project/survivalservers-studio/):

```bash
pip install survivalservers-studio
```

```python
import survivalservers_studio
```

This package installs nothing else, and importing it only raises an error that says the same.
