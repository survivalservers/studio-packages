`connect` waits at most 70 seconds for each part of an answer (above the API's longest wait of 60 seconds) and sends
the package's name and version as the User-Agent; pass `timeout=httpx.Timeout(70.0, read=None)` to follow a log
that may stay quiet for longer. `AuthenticatedClient` itself has no time limit.

Each call has `sync`, `sync_detailed` (with the status code and headers), `asyncio` and `asyncio_detailed`; a refusal
returns the API's `Problem`. A call the API did not do is tried again, 3 times in all: on `429 rate_limited` (any call),
and on `503 unavailable` for reads and for writes that carry an `idempotency_key`, waiting `Retry-After` up to 30
seconds. Never on `503 capacity_unavailable`, which is yours to answer (more regions, or later).
`AuthenticatedClient(..., retry=Retry(tries=..., max_wait=...))` changes it (`from survivalservers_studio.client import
Retry`; `Retry(tries=1)` turns it off). Generated by openapi-python-client (`survivalservers_studio/`, regenerate with
`../generate.sh`; `templates/client.py.jinja` is our client file, with the retry). Apache-2.0.
