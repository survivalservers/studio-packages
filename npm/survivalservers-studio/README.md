# survivalservers-studio

Another spelling of [@survivalservers/studio](https://www.npmjs.com/package/@survivalservers/studio), the
JavaScript and TypeScript client for the Survival Servers Studio API. Installing this name installs that package and
re-exports it. Use it directly:

```bash
npm install @survivalservers/studio
```

It has one dependency, @survivalservers/studio, and runs nothing when installed.

Published from https://github.com/survivalservers/studio-packages by Survival Servers. Licence: Apache-2.0.
